## 新踩的坑

- **`ELECTRON_RUN_AS_NODE=1` 环境变量会污染启动**：直接跑 `electron.exe .` 会报 `Cannot read properties of undefined (reading 'whenReady')`（require('electron') 退化成路径字符串）。启动前必须 `unset ELECTRON_RUN_AS_NODE`。
- **CDP 调试要绕两处**：`fetch`/`curl` 打 127.0.0.1 会走沙箱代理失败，需 `curl --noproxy '*'` 或用 `http.get({agent:false})`；且 electron 必须用 run_in_background 启动，`nohup &` 会随 shell 退出被杀。

## UI 二次升级（同日，用户要求对标 github.com/KnifeLemon/Filee）

### 参考项目的结论
- Filee 是 .NET/Avalonia 项目（不是 Electron），界面本身是 Fluent 风格的基础版，真正值得抄的是「品牌一致性」：
  侧栏品牌块 + 底部版本号/GitHub 入口 + 柔和强调色卡片 + 全自研的安装器（`src/Filee.Setup`，Avalonia 自绘 NSIS 替代品）。
- 行业对标（G HUB / Synapse 4）：设备视觉 + 卡片仪表盘 + 实时数据 + 每设备独立页签。最终按这个方向做，而不是照抄 Filee。

### 已落地
- **图标系统**：导航栏 5 个字符图标（◉⌨⚡≣✦）全部换成 inline SVG 线性图标；设置/语言按钮也换 SVG
  （设置原为齿轮，画出来像太阳，改成「滑杆」造型）。踩坑：`.icon-btn` 写在 `.btn` 之前会被 `.btn` 的
  `padding: 0 14px` 覆盖成 4px 宽，必须用 `.btn.icon-btn` 提高优先级并 `flex: 0 0 18px`。
- **侧栏**：宽度 150→176，底部加 GitHub 入口 + 版本号（`app:info` / `app:openExternal` 两个 IPC，外链仅允许 https）。
- **DPI 页双栏**：右侧新增「设备实时面板」——鼠标俯视线稿（SVG）+ LED 灯点跟随当前档位颜色 +
  回报率/当前档位/电量/板载配置四行数据。窗口 960×700 → 1080×720，minWidth 860；
  <1000px 时面板折到下方并横排统计、隐藏鼠标图形。新增文案 panelDevice/statDpi/statProfile。
- **键位中文化**：新建 `src/shared/keynames.js`（纯函数，40 个测试里的 8 个覆盖它），
  LEFT→左键、KeyA→A、Numpad1→小键盘 1、VOL_INC→音量加；**协议值不变**，只改显示。
  preload 暴露 `window.keynames.keyLabel(kind, value)`；切换语言时重建下拉（去掉 initMacroKeySelect 的永久 guard）。
- **电量 bug 修复**：设备休眠时 `0x89` 会回显命令字但数据全 0，原代码只校验 `buf[0]`，导致 UI 显示红色的 0%。
  现在 `level === 0` 直接视作无效读取（真实 0% 已关机，读不到）。
- **安装包品牌化**：`build/assets-src.html` + `build/make-assets.js` 用 Electron 自己渲染再截图，
  生成多尺寸 `icon.ico`（16~256，内嵌 PNG）+ `installerSidebar.bmp`(164×314) + `installerHeader.bmp`(150×57)，
  BMP 由 `nativeImage.toBitmap()` 的 BGRA 手写 24 位文件头（不依赖 ImageMagick）。
  NSIS 改 `oneClick:false` + `allowToChangeInstallationDirectory`（可选路径）+ 品牌侧图/图标，
  产物改名 `Incott-Mouse-Driver-Setup-${version}.exe`。
